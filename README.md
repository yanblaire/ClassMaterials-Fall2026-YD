# CIS 400 – Object-Oriented Design, Implementation, and Testing
## Fall 2026 Class Materials

Welcome to the class materials repository for **CIS 400 – Object-Oriented Design, Implementation, and Testing, Fall 2026**.

This repository contains materials used during class meetings throughout the semester. Materials will be organized by **week** and **class meeting date** so that you can easily locate resources from a particular class.

---

## Repository Contents

Materials posted here may include:

- PowerPoint slides used during class
- Source code written or demonstrated during class
- Example programs
- Code developed while discussing course concepts
- InnManager demonstrations
- Other supporting materials used during lectures

Not every class meeting will contain all of these materials. For example, some class meetings may contain only lecture slides, while programming-focused meetings may contain both slides and source code.

## InnManager Semester Project

Throughout the semester, we will develop **InnManager**, a hotel management application that serves as the semester-long project for CIS 400.

InnManager will be developed incrementally through a series of milestones. As we introduce new object-oriented design and software development concepts, those concepts will be applied to the project.

Code demonstrated during class may be provided in this repository when appropriate.
